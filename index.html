1

Create a new Google Sheet (sheets.google.com). Name it anything — e.g. CivMetrix Database.

2

In your Sheet click Extensions → Apps Script. Delete all existing code in the editor.

3

Copy the script below (click COPY), paste it into the Apps Script editor, then click the 💾 Save icon (Ctrl+S / ⌘+S).

4

In the editor toolbar click Deploy → Run function → initSheets. When prompted, grant permissions. This creates all required sheets with correct column headers — including ComplexActivities, SubContractors, SubContractorBOQ, SubContractorCosts, BOQMeasurements, IPC and all others. Re-run initSheets any time after an app update to add new sheets without affecting existing data.

5

Click Deploy → New deployment. Set type to Web app. Set Execute as: Me. Set Who has access: Anyone. Click Deploy and authorise when asked.

6

Copy the /exec URL shown (NOT the /dev URL). Paste it in the field below and click Save & Sign In.

!

Important: The URL must end in /exec. If you redeploy later, create a New deployment (not update existing) to get a fresh URL, or use Manage Deployments to find your current URL.
